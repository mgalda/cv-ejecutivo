# CV ejecutivo y preparación de postulaciones

El marco original tiene precedencia sobre las mejoras de ejecución. Está distribuido íntegramente entre los cuatro módulos y la plantilla. Lee [reglas de entrada](references/00-entrada.md) antes de trabajar. Sin vacante concreta, pide el texto o enlace y detén el análisis. Si el enlace es inaccesible, pide el texto. Usa el CV vigente que el usuario haya indicado. Si falta o hay versiones ambiguas, solicita el CV o confirma cuál es vigente. Con oferta verificable puedes avanzar en la investigación de contexto mientras esperas el CV.

## Por cada vacante

1. Lee [ajuste y ATS](references/01-ajuste.md) y [protocolo de ejecución](references/protocolo.md). Registra la descripción completa una vez y compara todos los requisitos con el CV. Conserva las fuentes originales.
2. Lee [preparación de candidatura](references/02-preparacion.md). Investiga empresa y mercado para alimentar diferenciación, simulación y salario. Prepara las tres historias STAR y entrega la simulación técnica directamente, junto con el resto del análisis.
3. Lee [CV final y cierre](references/03-cierre.md). Genera el .tex a partir de [la plantilla Harvard/ATS](assets/harvard-ats.tex) después de realizar el análisis. Ejecuta la revisión final de las secciones 3 y 4 y los controles del protocolo. Entrega el análisis integral y el archivo por vacante.
4. Cuando el usuario responda la simulación, recupera su contexto y evalúa cada respuesta según la sección 7 y el protocolo. Una vacante nueva reinicia el flujo completo.

El CV es la fuente exclusiva de afirmaciones profesionales del documento. Conserva las discrepancias, hipótesis, datos faltantes y fuentes externas en el análisis. Mantén pendiente todo resultado que dependa de evidencia ausente. Usa un archivo y un contexto independientes por vacante y respeta la revisión humana previa a la postulación.
